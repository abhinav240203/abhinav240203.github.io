Selected

PROJECT 01

Robot Path Planning with Costmap

Engineered A* and Dijkstra global path-planning algorithms integrated directly into a ROS 2 costmap framework to compute collision-free trajectories. Utilized TF2 for real-time robot pose transformations and published custom costmap and path data for visualization in RViz.

ROS 2 C++ A* Dijkstra TF2 RViz2

PROJECT 02

Articulated Robot Design

Modeled an articulated robotic manipulator in MATLAB/Simulink, utilizing Signal Editor to simulate custom input trajectories and multi-body dynamics. Developed forward and inverse kinematics solvers to compute joint configurations for desired end-effector positions.

MATLAB Simulink Forward Kinematics Inverse Kinematics Dynamics
View Project on GitHub ↗
PROJECT 03

PD Motion Planner, Controller & Pure Pursuit

Implemented a Pure Pursuit path-tracking controller featuring configurable look-ahead distance and dynamic velocity limits based on path curvature. Leveraged TF2 coordinate transformations and AMCL localization to translate global planned trajectories into precise velocity commands.

ROS 2 Pure Pursuit TF2 AMCL Motion Planning Control
View Project on GitHub ↗
PROJECT 04

Odometry Comparison

Developed and evaluated robot odometry estimation approaches for mobile robot localization and motion analysis. Compared motion estimates and investigated differences between odometry sources using ROS 2 tools and visualization.

ROS 2 Odometry TF2 RViz2 Robot Localization
View Project on GitHub ↗
PROJECT 05

Robotic Gripper — SolidWorks

Designed a two-finger robotic gripper with interconnected links and a gear mechanism for synchronized finger movement. Developed the assembly using concentric, coincident, tangent, gear and limit-angle mates and tested the opening and closing motion of the mechanism.

SolidWorks CAD Assembly Mechanism Design Gear Mechanism
